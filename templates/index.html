RESEARCH NOTES

Methodology & limitations

01

Dataset generation

The existing Python generator creates datasets at 1,000, 5,000, 10,000, 50,000 and 100,000 records.

02

AVL Tree search

The AVL tree is built before the timer starts. The benchmark then times searches for 100 existing keys.

03

SQLite indexed search

The table and data are prepared before the timer starts. The same 100 existing keys are searched.

04

Measurement

Python's high-resolution performance timer measures the search loop. Total time is divided by 100.

05

Validation

The original benchmark returns the final search result from each implementation, not a separate result for every key.

06

Limitations

Results depend on the machine, runtime, database configuration and timing noise. Repeated trials improve confidence.
